# Changelog

## 0.2.0-local

- Replace the foundation status screen with Home, Library, Search and Player screens.
- Import files and folders, scan MediaStore, browse albums/artists/folders/genres, sort and search local music.
- Add one Media3 playback service with queue controls, background media session, focus/noisy handling and paused restoration.
- Add vinyl/CD views, album-art colors, reduced motion and mini player.
- Persist favorites, playlists, ordering, history, counts and imported lyrics; expose supported Android audio effects.
- Add configurable ClashFLAC catalog metadata search. Online streaming/downloads remain unavailable.
- Add real Android UI, persistence, service and codec checks; see test report for executed results.

## 0.1.0-foundation

- Initial Android build/test foundation. Superseded as the downloadable APK by the local-player build.
