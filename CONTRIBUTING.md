# Contributing

This project is at its Android foundation gate. Read docs/ARCHITECTURE.md and docs/TEST_PLAN.md before adding features. Include deterministic unit tests and execute real Android instrumentation for platform behavior. Keep one playback session, use content URIs and background-safe IO, and never bundle copyrighted music or credentials. Do not enable an online provider without an audit and documented permitted playback/download capabilities.

Run the commands in docs/BUILD_AND_RELEASE.md and record actual results in docs/TEST_REPORT.md. Unexecuted CI and emulator checks must remain pending.
